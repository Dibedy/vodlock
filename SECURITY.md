# Security policy

## Reporting a vulnerability

Please do not disclose a security vulnerability in a public issue. Use GitHub's private vulnerability reporting for this repository when available, or contact **@dibedy** privately on Discord.

Include the affected component, a concise reproduction, and the expected impact. Do not include real access tokens, account cookies, private VODs, or other people's personal information.

## Scope

Security fixes target the current `main` branch. The website is static, Round Studio binds to localhost, and repository credentials are supplied through GitHub Actions secrets rather than committed files.
